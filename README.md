# FinkaCare — Prototype UI Admin Stok Apotek

Prototype frontend statis untuk presentasi rancangan website admin stok Apotek Finka.

## Cara menjalankan
- Buka `index.html` langsung di browser, atau
- Deploy folder ini sebagai project statis di Vercel.

## Catatan penting
- Ini hanya prototype UI; tidak menggunakan Supabase, database, atau backend.
- Form dan tombol hanya simulasi. Perubahan tidak tersimpan permanen.
- Beberapa angka ringkasan diambil dari pemeriksaan struktur workbook awal; data tabel dan status operasional adalah contoh/demo dan tidak boleh digunakan sebagai saldo stok aktual.
- Sebelum operasional, validasi data awal, stok fisik, batch, tanggal kedaluwarsa, dan satuan konversi terlebih dahulu.
